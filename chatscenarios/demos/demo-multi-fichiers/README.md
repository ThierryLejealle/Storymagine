# demo-multi-fichiers : une salade de fruits

Montre un scénario coupé en plusieurs fichiers : `scenario.txt`, puis `scenario-1.txt`, `scenario-2.txt`
(numéros consécutifs). Ils sont concaténés dans l'ordre ; chacun commence par un titre `#` de premier niveau.

À regarder : trois actes, un par fichier. Utile pour les longs scénarios.
Guide : §1.
