# demo-pnj : deux amis au café

Montre plusieurs personnages (un fichier par fiche dans `characters/`) et le choix de qui répond.

- Écrire « Iris » ou « Théo » dans un message : le personnage nommé répond.
- Sans nom : le dernier qui a parlé continue, sinon un des deux est tiré au hasard.
- Les vignettes montrent le niveau d'activité de chacun.

À regarder : ❓ explique pourquoi un personnage a répondu.
Guide : §4.1, §4.2.
