# demo-npc-starts : la boulangère

Montre `{npc-starts}` : c'est le personnage, pas le joueur, qui parle en premier.

- Dans l'en-tête : Rose ouvre l'histoire. Elle parle la première, **sans aucun message du joueur** (pas de bulle « DO: »).
- Dans le second acte : Rose ouvre aussi cet acte dès qu'il devient courant.
- Sans nom, un personnage présent serait tiré au hasard.
- C'est une ouverture normale : Rose joue seulement son personnage. Pour une ouverture où le personnage tient la
  plume du narrateur, voir `{npc-do}` et `demo-npc-do`.

À regarder : la partie démarre sans que le joueur écrive rien.
Guide : §4.5.
