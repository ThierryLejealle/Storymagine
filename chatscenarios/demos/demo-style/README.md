# demo-style : parler de la météo

Montre `style.txt` : un conseil de style donné à tous les personnages.

- La première ligne est toujours envoyée.
- Les lignes avec `{40%}` et `{20%}` ne sont envoyées qu'avec cette probabilité, tirée à chaque réponse.

À regarder : après une réponse, 🐞 affiche le style tel que le personnage l'a réellement reçu.
Guide : §2.10.
