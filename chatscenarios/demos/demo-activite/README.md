# demo-activite : le palier

Montre les niveaux d'activité des personnages.

- Acte 1 : `npc-active Ana` (parle à chaque échange), `npc-passive Ben` (réagit rarement), `npc-absent Cléo` (n'est pas là).
- Acte 2 : `npc-reset` remet tout le monde en présent.

À regarder : les vignettes changent d'un acte à l'autre.
Guide : §2.11, §4.1.
