# demo-actes : une promenade en trois temps

Montre la structure en actes et la progression.

- Un titre `#` parent (« La promenade ») dont le texte est partagé par ses trois scènes `##`, qui sont les actes jouables.
- Les lignes `[...]` : narration affichée au joueur à l'entrée dans chaque acte.
- `Quand écrire [NEXT ACT]` : la condition qui fait passer à l'acte suivant (absente du dernier acte).

À regarder : les boutons « Précédent » / « Suivant », et 🔍 pour voir si la condition est remplie.
Guide : §2.3, §2.4, §2.5, §4.5.
