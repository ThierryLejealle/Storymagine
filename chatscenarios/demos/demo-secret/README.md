# demo-secret : un carton mystérieux

Montre la section `# SECRET` d'une fiche personnage : la partie après cette ligne n'est lue que par le personnage lui-même.

- Avec un seul personnage, le secret guide son comportement (il esquive sur le carton).
- Avec plusieurs personnages, les autres ne reçoivent que la partie publique de la fiche.

À regarder : essayer de faire parler Bernard du carton.
Guide : §3.
