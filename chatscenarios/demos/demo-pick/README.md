# demo-pick : un goûter

Montre `{pick type nom}` : des paragraphes tirés dans `picks/nom.txt` au début de chaque partie.

- `random boisson` : un paragraphe, tirage indépendant (prémisse).
- `unique gateau` (deux fois) : deux gâteaux forcément différents.
- `2 gourmandise` : deux paragraphes différents.
- `all regles` : tous les paragraphes, dans l'ordre du fichier.

À regarder : le bouton 🎲 affiche le tableau des tirages. « Recommencer » tire à nouveau.
Guide : §2.6.
