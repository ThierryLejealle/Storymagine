# demo-delta-pnj : un cadeau d'anniversaire

Montre `delta-pnj` (public ou secret) : faire évoluer la fiche d'un personnage en cours d'histoire.

- `public` (le chapeau de Jules) : tous les personnages présents le savent.
- `secret` (le cadeau de Camille) : seule Camille le sait ; Jules ne le lit jamais.

À regarder : à l'acte 2, Camille garde son cadeau sans que Jules le devine. 🐞 montre le texte envoyé.
Guide : §2.8.
